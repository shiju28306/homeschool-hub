Requests go to Homeschool Hub — we review if it’s a good free printable, then make and publish it when appropriate. Not every ask will be built.

Parents and students welcome. Submit opens GitHub with your details filled in — confirm there to send it to the Homeschool Hub bot. You’ll need to be signed in to GitHub (or sign in when prompted).

Who is requesting?

Submit request opens a prefilled GitHub issue — review and create it there so Homeschool Hub can see it. If you aren’t logged in, GitHub will ask you to sign in first. Prefer not to use GitHub? Use Copy request and paste it anywhere handy. We review each ask; not every request becomes a printable.
