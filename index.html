Request materials

Requests go to Homeschool Research first. They review each ask; when it’s a good fit, they brief Homeschool Hub to make and publish a free printable. Not every ask will be built.

For parents, carers and educators. Requests are public on GitHub. Do not include names of children, email addresses, school details or other personal information. Submit opens a draft for you to review and confirm on GitHub; you will need a GitHub account.

Who is requesting?

Submit request opens a prefilled GitHub issue — review and create it there so Homeschool Research can review it. If you aren’t logged in, GitHub will ask you to sign in first. Prefer not to use GitHub? Use Copy request and paste it anywhere handy. Not every request becomes a printable.
